# NutriMotion

## Descripción
NutriMotion es una aplicación móvil desarrollada en **Flutter**, pensada para funcionar en dispositivos Android.  
Actualmente el proyecto está configurado para correr en un dispositivo real conectado por USB o en un emulador Android.  

Este repositorio fue inicializado como proyecto Flutter dentro de un repositorio Git compartido, respetando las buenas prácticas de control de versiones y estructura de proyecto.

---

## Tecnologías utilizadas

- **Flutter SDK**: Framework principal para el desarrollo de aplicaciones móviles multiplataforma.
- **Dart**: Lenguaje de programación utilizado por Flutter.
- **Android Studio**: IDE utilizado para gestionar el Android SDK y emuladores.
- **Cursor / VS Code**: Editor de código utilizado para programar la aplicación.
- **Git y GitHub**: Control de versiones y colaboración en equipo.

---

## Estructura del proyecto

- `lib/` → Contiene el código principal de Flutter (`main.dart` y demás widgets).
- `android/` → Configuración nativa de Android.
- `ios/` → Configuración nativa de iOS.
- `build/` → Carpeta generada automáticamente por Flutter al compilar (no subir a Git).
- `.gitignore` → Ignora archivos generados por Flutter, IDEs y logs.
- `pubspec.yaml` → Archivo de configuración de dependencias y assets de Flutter.
